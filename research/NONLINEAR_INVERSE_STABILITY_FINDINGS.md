# Exact uniqueness can coexist with poor source recovery

**Accepted analytic result, 29 September 2026.** In the specified axisymmetric graph model, two exact profiles can uniquely determine smooth compact sources at a nonflat baseline, while no source-recovery Lipschitz bound remains uniform as the profiles approach flatness. The result requires an **unknown smooth compact balanced vertical load**; it is not a second explanation with the load known to be zero.

Let epsilon be the small source amplitude. Starting with the previously proved stationary profiles at known tensions 1 and 2, change the prescribed curvature from epsilon phi to 2 epsilon phi. An exact compensating load preserves the first profile. A uniform local elliptic inverse constructs an actual second stationary profile under the same changed sources. The source difference has size epsilon, while the complete normalized-slope profile-pair difference is at most C epsilon cubed. Thus any inverse Lipschitz constant on a set containing these pairs is at least c/epsilon squared. This is a lower bound, not an optimal rate or a numerical estimate.

The [theory](NONLINEAR_INVERSE_STABILITY_THEORY.md) names weighted C^{3,alpha} profile norms and a C^{2,alpha} curvature-source norm, proves the load sign, compactness, origin regularity and zero net force, and constructs actual stationary graphs. A small equation residual alone would not suffice. The [independent review](NONLINEAR_INVERSE_STABILITY_REVIEW.md) accepted the argument after one same-attempt wording correction: O(epsilon) closeness of the flux derivative to the screened operator holds on a shrinking C epsilon ball, not uniformly on a fixed-radius ball. Lead inspection confirms the correction and accepts the result within those norms and source conventions.

The contrast is informative: exact source uniqueness is weaker than useful recovery from imperfect observations. Neither result establishes dynamic stability, a practical epsilon threshold, calibrated pixel-noise tolerance, global uniqueness or a biological mechanism. No claim of literature novelty has been assessed. These are complete mathematical profiles with derivatives, not fitted cap summaries.
