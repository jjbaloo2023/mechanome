# Review checkpoint protocol

Written before running the following additional scenarios. The earlier comparison
has already been seen: these are exploratory diagnostic checks, not confirmation.

1. Construct a negative control with constant curvature within every synthetic
   pit, heterogeneous curvature between pits, and phase-dependent sampling.
   Apply the same grouped comparison to one snapshot per pit. If the flexible
   reference wins, block any inference from that ranking alone to changing
   curvature within individual pits. This is a constructed possibility, not a
   demonstration that this sampling process occurred experimentally.
2. On the primary corrected/unflagged population, add -10, 0 or +10 nm to implied
   radius using H' = H/(1 + delta*H). Keep zero curvature at zero and reject
   nonpositive implied radius. These uniform shifts follow the type of linkage
   sensitivity illustrated in Mund Fig. S5; they are not estimated distributions.
3. Repeat each shift with all angles and with 20–160 degrees only. This endpoint
   exclusion is motivated by angle-estimation concerns in Fig. S2. Use identical
   filtering for all candidates and retain the fixed knots and original scoring.
4. Save every fold and all scenarios, including reversals. Do not substitute
   these scenarios for the unavailable joint angle/curvature error calibration.

Source: [Mund et al., supplementary Figs. S2 and S5](https://research-explorer.ista.ac.at/download/14788/14811/2023_JCB_Mund.pdf).

Execution is a self-audit by the implementing assistant. It cannot satisfy the
roadmap's independently briefed reviewer requirement. Final disposition must keep
that requirement unresolved and refrain from promoting a mechanistic claim.
