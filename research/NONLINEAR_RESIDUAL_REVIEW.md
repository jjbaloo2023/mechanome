The postmortem input SHA-256 values match the frozen attempt-2 result and NPZ, and its script hash matches the file reviewed. All 12 assertions hold. The original fixed-grid maxima match the frozen attempt-2 measurements.

The decomposition is exact. With `d=v'-w`, `A=1-r^2*v^2`, and `T=2*v+r*w-c`, subtracting the auxiliary first-order-system flux from the physical flux of the interpolated graph gives

`Q_physical/r - Q_system/r = -A*(3*d/r+d') - r*v*d*(v+r*w) - 0.5*v*r^2*d^2`.

At the regular origin its limit is `-4*d'(0)`. The code uses actual PPoly derivatives `v''` and `w'` to evaluate these terms; it does not substitute the ODE right-hand side into the physical residual. The saved decomposition error is below `1.1e-15` after normalization. The auxiliary system flux is a diagnostic, not the physical gate.
