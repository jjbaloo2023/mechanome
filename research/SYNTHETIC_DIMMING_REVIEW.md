# Independent review: fixed synthetic dimming benchmark

Task `synthetic-dimming-review-001`, 2026-09-29. Reviewed the [registered design](synthetic_dimming_design.json), [benchmark implementation](synthetic_dimming_benchmark.py), [results](synthetic_dimming_results.json), [checks](synthetic_dimming_checks.json), and unchanged `validation/tracking.py`. I did not rerun the 135-movie grid, execute author code, use external data, or run a physical inverse.

**Core disposition: the saved pre-detection coverage calculation is mathematically and implementationally supported within its synthetic scope, but execution exceeded the registered movie budget.** The grid has 3 durations × 3 peak signals × 5 seeds = 45 latent one-event movies, each rendered at gains 1, 0.6 and 0.3 with identical geometry and a paired Gaussian read-noise array. One main execution uses 135 grid runs plus five no-event negatives and one noise-free high-SNR positive, or **141** movies. The numerical worker confirmed that main ran **twice**, for **282 actual tracker movies**, exceeding the 150-run cap by 132. Only the second run's output and source version were retained; the first-run artifacts cannot be audited. This is a material protocol deviation, so the result must not be presented as a strictly budget-compliant preregistered execution. The saved code calls the tracker with registered `gate_px=4`, `max_gap=0`, `min_track_len=4` and existing detection gates; its tracker source hash matches the registered hash. No parameter retuning is evident in the retained implementation.

The custom score correctly avoids the legacy `validate_tracking` denominator. A retained point matches only within 3 px of the known center **and** during latent event presence. Matched frame coverage is the union across retained fragments; missed events contribute zero coverage to the fixed 45-event and 1,440-ground-truth-frame denominators, while their observed spans remain `null`. False-positive points are counted among **retained-track points**, not all raw detections. The union span is inclusive first-to-last matched frame and could bridge a gap, so it is not necessarily a continuous track lifetime. In these outputs total matched fragments equal matched events at each gain, so no multi-fragment event is observed. The high-SNR noise-free control has one 48-frame matched track and full eligible coverage; all five no-event noise controls have zero raw detections and retained tracks.

I independently checked the fixed 1,440 truth-frame arithmetic and the gain-specific eligible denominators (1,220, 1,060, 530) from the registered sinusoidal signal plus background and the noiseless center threshold of 25. The conditional numerator is restricted to those same eligible frames. At gain 0.3, the 15 missing events are all peak-60 cases whose maximum noiseless center is 23, below the 25 gate; they have no eligible frames. Thus the high conditional fraction at low gain does not imply full-cohort recovery. The span mean is conditional on survivors and changes cohort composition; it is not a paired estimate of latent lifetime change.

**Comparator qualification and completed supplement.** The original `post_tracking_comparator` in the benchmark copies gain-1 track IDs and frame supports for gains 0.6/0.3 and stores a string describing intensity rescaling; it does not itself transform values. The separate [reanalysis](synthetic_dimming_reanalysis.py) and [audit output](synthetic_dimming_reanalysis.json) independently recompute all 135 rows' truth, eligible and matched-frame arithmetic, verify all 45 baseline noise hashes, and perform 90 numeric transforms on raw pixels sampled at the known fixed center over frozen gain-1 matched frames: `I_post,g = 5 + g (I_base,center - 5)`. It made **zero new tracker calls**. This post-main center sampler is a declared local synthetic estimator, not detector-coordinate photometry or an existing `run_tracking` intensity extractor. The numeric transform and unchanged copied supports support the narrow contrast: post-tracking intensity arithmetic cannot change the original track identities, frame supports, coverage or spans, whereas dimming before detection does. The core pre-detection result does not depend on this supplement.

The benchmark demonstrates sensitivity of this detector/tracker to dimming before detection under one simplified stationary single-spot noise model. It does not calibrate DASC, imply that biological conditions differ only by scalar brightness, test a clathrin mechanism, or infer force. Separately, legacy `validate_tracking` mixes detectable-only FN with TP that can include below-threshold GT matches; a distinct metric-contract repair would be warranted before relying on that validator, but it is outside this frozen benchmark.
