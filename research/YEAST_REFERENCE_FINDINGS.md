# Figure 6 motion comparison stops at an access gap

The sole [methods follow-up](yeast_reference_methods_design.json) did not
establish the spatial reference and physical-time alignment needed to compare
40-to-80 nm transits across the four stored Sla1 mean curves. The [independent
review](YEAST_REFERENCE_REVIEW.md) accepts that limit. No transit was calculated.

One indexed primary query returned a Figure 3 caption with an initial positional
baseline and onset alignment. Its applicability to the deposited Figure 6 curves
was not established. Both permitted direct publisher opens returned HTTP 403:
[article PDF](https://elifesciences.org/articles/44215.pdf) and
[figures](https://elifesciences.org/articles/44215/figures). This is an access and
definition gap, not evidence that the paper lacks the method. A clearly applicable
global method would have sufficed; a literal cross-reference or identical x/y
letter is not required. The [source ledger](YEAST_REFERENCE_SOURCE.md) records
one query, three no-match text finds, two opens and zero local downloads.

The reviewer distinguishes an arbitrary numeric curve functional from a comparison
of the same physical displacement interval. Constant time offsets cancel in
transit durations; vertical offsets and time warping do not. Changing cohort n
would further limit interpretation even with common coordinates. The [four Act1
medians and four source curves](YEAST_FIGURE6_FINDINGS.md) remain verified public
aggregates. Their availability does not supply event covariance, force, scission
or causal rescue evidence.

The lead required completing the already-permitted primary opens after the
initial snippet-only source note stopped early. Source/reviewer removed an
unsupported positive-direction assertion and retained the distinction between
Figure 3 and Figure 6 control reuse. The final source/review were read before
acceptance. This methods stage and the yeast motion comparison now stop; no
further automatic access or coordinate-repair stage is queued.

## Chosen next action

Repeated source searches have diminishing value. The existing [DASC observation
decision](DASC_OBSERVATION_DECISION.md) already identifies a narrower useful
benchmark: dimming before detection can change which tracks exist. We will test
that pipeline behavior on a small, explicitly synthetic cohort with unchanged
latent lifetimes, using the existing local tracker. This does not reopen the
parked DASC biological-mechanism comparison, download experimental movies or
claim an imaging explanation for a published phenotype. It tests a software
observation boundary that can later constrain a legitimate empirical comparison.
